# 🎓 UniWallet

**UniWallet** is a premium, high-fidelity student finance tracker designed to help students manage their money with ease. It features a modern, "solar-themed" UI with bento-grid layouts, glassmorphism, and smooth animations.

## ✨ Features

- **Dashboard:** Overview of total balance, income, and expenses with dynamic charts.
- **Budgeting:** Set and track spending limits across categories.
- **Recurring Expenses:** Manage subscriptions and regular bills.
- **Loans & Debt:** Keep track of who owes you and who you owe.
- **PWA Ready:** Install UniWallet on your phone or desktop for an app-like experience.
- **Dark Mode First:** A beautiful dark-themed interface designed for modern screens.

## 🛠️ Tech Stack

- **Frontend:** Vanilla HTML5, CSS3 (Custom Design System), JavaScript (ES6+).
- **Storage:** LocalStorage for private, on-device data persistence.
- **Service Worker:** Offline support and PWA capabilities.

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/afsalahamad/UniWallet.git
   ```
2. Open `index.html` in your browser.
3. (Optional) Install as a PWA via the browser address bar.
